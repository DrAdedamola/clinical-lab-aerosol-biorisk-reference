# Glossary

Plain definitions of every term you will meet in this project.

**Aerosol** — particles small enough to stay suspended in air and be breathed in. Different
from a splash, which falls. The distinction matters because the controls are different:
a face shield stops a splash and does nothing about an aerosol.

**Aerosol-generating procedure (AGP)** — a step that puts such particles into the air.

**Anchor** — the written description of what a score of 1, 2, 3, 4 or 5 means for one item.
Anchors are what let two different people reach the same score.

**Biorisk** — the combination of how likely a biological harm is and how bad it would be.
Covers both biosafety (accidents) and biosecurity (deliberate misuse).

**BRACE** — biorisk assessment, characterization and evaluation. The approach this
instrument applies at the level of a single bench step.

**BSC, biological safety cabinet** — an enclosed, ventilated workbench that draws air away
from the worker and filters it. The main engineering control in a microbiology laboratory.

**CLIA** — the US law under which every laboratory testing human specimens must be
certified. "Moderate and high complexity" are the certificate categories where the steps
in this reference take place.

**Codebook** — the document that defines every column in every data file.

**DOI** — digital object identifier. A permanent citation number for a piece of work, like
a library call number that never changes even if the web address does.

**Engineering control** — a control built into the equipment or the room, rather than into
what a person remembers to do. Ranked above administrative controls and PPE because it does
not depend on anyone having a good day.

**Evidence grade (E1 to E5)** — this project's measure of how much is actually known about
a step. E1 means somebody measured it. E5 means nobody has.

**Gwet's AC2** — a statistic for how much two raters agree, which behaves sensibly when
most ratings fall in the middle of the scale. Used here instead of relying on kappa alone.

**Inter-rater agreement** — how often two people scoring the same thing, separately, reach
the same answer. The test of whether an instrument is an instrument.

**ISO 35001:2019** — the international standard for biorisk management in laboratories.
This project uses its clause numbers and titles as an index, so a laboratory can point at
the clause each recommendation satisfies.

**Kappa** — an older agreement statistic. Reported here alongside AC2 for comparison.

**LAI, laboratory-acquired infection** — an infection caught at work in a laboratory.

**MALDI-TOF** — a mass spectrometer used to identify bacteria from a colony in minutes.

**PPE** — personal protective equipment. Gloves, coats, eye protection, respirators. The
last line of defence, not the first.

**Provenance** — the record of where each piece of information came from and when.

**RBI, Residual Biorisk Index** — this project's headline number for a step, on a 1 to 25
scale, after the controls in place have been credited.

**Repository** — a project folder that lives online and keeps every past version of every
file, so anyone can see what changed and when. GitHub hosts repositories.

**Sentinel laboratory** — a frontline clinical laboratory whose job in the national network
is to recognise a possible dangerous organism, rule it out if it can, and refer it onward
if it cannot.

**Stats file** — a single machine-readable file holding every number the project's documents
quote. Documents read from it, so the text and the data cannot disagree.

**Zenodo** — a free, permanent repository run by CERN that gives your work a DOI.
